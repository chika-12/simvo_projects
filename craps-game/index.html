HavenHub

modular monolith

One platform for hotel management, short/long-term rentals and property sales — with a Risk Intelligence layer working quietly underneath, never surfaced to users as "fraud detection."

  • Hotel-scoped RBAC via a dedicated permissions guard, checked against the database rather than filtered in memory
  • Address + Hotel creation wrapped in a single TypeORM transaction to avoid orphaned rows
  • Event-driven hooks (hotel.created, booking.created) planned for notifications and risk scoring, without blocking the main request
NestJSPostgreSQLTypeORM

SkillUp Africa

microservices

A NestJS microservices EdTech platform for secondary schools in Nigeria, built in-house while I teach students on the same curriculum it serves.

  • Auth, gateway and school services talk over TCP inside a pnpm monorepo
  • Compensating transactions roll back a partially-created student across services if one write fails
  • Per-term billing designed around Paystack, with eventual consistency for payment state

KDC School Management System

live in production

A CBT exam and results backend for a Nigerian NGO school, built around Exam as the entity that everything else schedules itself off.

  • Cron-automated timetable status controls when students can even enter an exam session
  • Results auto-score against WAEC grade bands from combined CBT and written scores
  • Deployed and running on Render, which is what made the cron work worth building in the first place
