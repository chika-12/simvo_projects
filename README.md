# simvo

A collection of learning projects and small builds, organized as a monorepo.

## Projects

| Folder                                            | Description                                                                                   |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| [`complex-data-types/`](./complex-data-types)     | Exercises covering complex data types (arrays, objects, etc.) in JavaScript and Python        |
| [`primitive-data-types/`](./primitive-data-types) | Exercises covering primitive data types (strings, numbers, booleans) in JavaScript and Python |
| [`craps-game/`](./craps-game)                     | A browser-based dice betting game built with vanilla HTML/CSS/JS                              |
| [`portfolio/`](./portfolio)                       | Personal backend engineer portfolio site                                                      |
| [`text-analysis-tool/`](./text-analysis-tool)     | A Python tool for basic text analysis (word counts, frequency stats)                          |

## Structure

Each folder is a self-contained project with its own code and, where relevant, its own README with setup and usage instructions.

## Getting started

Clone the repo, then `cd` into whichever project you want to run:

```bash
git clone <repo-url>
cd simvo/<project-folder>
```

See each project's individual README for specific setup steps.
