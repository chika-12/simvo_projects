This repo is my working record of going through JavaScript and Python's primitive data types — covering their core behaviors and how to use them in practice.

Key takeaways along the way:

Strings and Numbers aren't just raw values — they come with their own properties and methods attached, since they behave as objects under the hood
Those built-in methods cover the overwhelming majority of everyday operations on their own
Both languages also ship extra built-in functions beyond the type methods themselves, extending what's possible
Some tasks are simply a better fit for Python, others for JavaScript — the right tool depends on the job
Underneath the surface, most languages converge on similar capabilities; what changes is how each one implements them

Running the tests:

Fork and clone the repo, then run ./run-all.sh from the project root
If it won't execute, grant it permission first: chmod +x run-all.sh
Individual test files can be run directly too — e.g. node strings/strings.js for the JS string exercises
