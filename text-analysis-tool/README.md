# Text Analysis Tool

A simple Python tool for analyzing text — word counts, frequency stats, and basic text metrics.

## Requirements

- Python 3.8+

## Installation

```bash
git clone <repo-url>
cd <repo-folder>
pip install -r requirements.txt
```

## Usage

```bash
python analyze.py
```

## Output

Prints basic stats about the input text, such as word count, sentence count, and most frequent words.
